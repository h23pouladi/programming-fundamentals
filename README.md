## مقدمه

این سند یک آموزش کامل و گام‌به‌گام برای یادگیری **اصول برنامه‌نویسی** است. هدف این است که در پایان، با مفاهیم پایه‌ای مثل متغیر، شرط، حلقه، تابع و ساختارهای داده آشنا شده باشید و بتوانید اولین برنامه‌های خود را بنویسید.

## برنامه‌نویسی چیست؟

برنامه‌نویسی یعنی نوشتن دستوراتی که رایانه می‌تواند آن‌ها را اجرا کند تا یک مشکل خاص حل شود. یک برنامه مجموعه‌ای مرتب از دستورات است:

- **ورودی (Input):** داده‌ای که برنامه دریافت می‌کند.
- **فرایند (Process):** پردازش و محاسبه روی داده‌ها.
- **خروجی (Output):** نتیجه‌ای که برنامه ارائه می‌دهد.

### الگوریتم چیست؟

الگوریتم دنباله‌ای از مراحل مشخص و مرتب است که حل یک مسئله را توصیف می‌کند. مثال ساده: الگوریتم جمع دو عدد:

1. عدد اول را بگیر.
2. عدد دوم را بگیر.
3. آن‌ها را با هم جمع کن.
4. نتیجه را نمایش بده.

### زبان‌های برنامه‌نویسی

- **زبان‌های سطح بالا:** Python، JavaScript، Java — نزدیک به زبان انسان و آسان برای یادگیری.
- **زبان‌های سطح پایین:** اسمبلی، C — نزدیک‌تر به سخت‌افزار و سریع‌تر، اما سخت‌تر.
- **کامپایلر:** کد را یک‌جا به زبان ماشین ترجمه می‌کند (مثل C).
- **مفسر:** کد را خط‌به‌خط اجرا می‌کند (مثل Python).

## متغیرها و انواع داده

**متغیر** ظرفی است برای نگهداری داده در حافظه. هر متغیر یک *نام* و یک *مقدار* دارد.

### انواع داده پایه

| نوع داده | توضیح | مثال |
|---|---|---|
| عدد صحیح (Integer) | اعداد بدون اعشار | `42`, `-7` |
| عدد اعشاری (Float) | اعداد با ممیز | `3.14`, `-0.5` |
| رشته (String) | متن | `"سلام"` |
| بولی (Boolean) | درست یا غلط | `True`, `False` |

### مثال در پایتون

```python
name = "علی"        # رشته
age = 25            # عدد صحیح
height = 1.78       # عدد اعشاری
is_student = True   # بولی

print(name, age, height, is_student)
```

### قوانین نام‌گذاری متغیرها

- نام باید معنادار باشد: `score` بهتر از `x`.
- نمی‌تواند با عدد شروع شود.
- نمی‌تواند از کلمات رزرو شده زبان باشد.
- در پایتون از `snake_case` و در جاوااسکریپت معمولاً از `camelCase` استفاده می‌شود.

## عملگرها

### عملگرهای حسابی

| عملگر | عمل | مثال |
|---|---|---|
| `+` | جمع | `5 + 3` → `8` |
| `-` | تفریق | `5 - 3` → `2` |
| `*` | ضرب | `5 * 3` → `15` |
| `/` | تقسیم | `6 / 3` → `2.0` |
| `//` | تقسیم صحیح | `7 // 2` → `3` |
| `%` | باقیمانده | `7 % 2` → `1` |
| `**` | توان | `2 ** 3` → `8` |

### عملگرهای مقایسه‌ای

| عملگر | معنی |
|---|---|
| `==` | برابر است با |
| `!=` | نابرابر است با |
| `>` / `<` | بزرگ‌تر / کوچک‌تر |
| `>=` / `<=` | بزرگ‌تر مساوی / کوچک‌تر مساوی |

### عملگرهای منطقی

- `and` — هر دو شرط درست باشند.
- `or` — حداقل یکی درست باشد.
- `not` — برعکس کردن نتیجه.

## ساختارهای کنترلی (شرط‌ها)

با شرط‌ها برنامه می‌تواند بر اساس وضعیت، مسیرهای مختلف را طی کند.

```python
score = 18

if score >= 17:
    print("خیلی خوب")
elif score >= 12:
    print("قبول")
else:
    print("مردود")
```

نکته: در پایتون تورفتگی (indentation) بخشی از دستور زبان است و بلوک کد را مشخص می‌کند.

## حلقه‌ها

حلقه برای اجرای مکرر یک بلوک کد استفاده می‌شود.

### حلقه `for` — وقتی تعداد تکرار مشخص است

```python
for i in range(5):
    print(i)   # 0 تا 4 چاپ می‌شود
```

### حلقه `while` — وقتی شرط مهم است

```python
count = 3
while count > 0:
    print(count)
    count -= 1
```

### دستورات کنترل حلقه

- `break` — خروج کامل از حلقه.
- `continue` — رد شدن به تکرار بعدی.

## توابع

**تابع** بلوکی از کد با نام مشخص است که یک کار مشخص انجام می‌دهد و قابل استفاده مجدد است.

```python
def greet(name):
    """سلامی به نام شخص می‌سازد."""
    return f"سلام، {name}!"

print(greet("سارا"))   # خروجی: سلام، سارا!
```

### مزایای توابع

- **استفاده مجدد (Reusability):** یک‌بار می‌نویسید، چندبار استفاده می‌کنید.
- **خوانایی:** کد کوتاه‌تر و مرتب‌تر می‌شود.
- **تست‌پذیری:** هر تابع را جداگانه می‌توان آزمود.

## ساختارهای داده

### لیست (List)

مجموعه‌ای مرتب و قابل تغییر:

```python
fruits = ["سیب", "موز", "پرتقال"]
fruits.append("کیوی")
print(fruits[0])       # سیب
print(len(fruits))     # 4
```

### دیکشنری (Dictionary)

جفت‌های «کلید-مقدار»:

```python
person = {"name": "رضا", "age": 30}
print(person["name"])  # رضا
```

### تاپل (Tuple) و مجموعه (Set)

- **تاپل:** مثل لیست ولی *غیرقابل تغییر* — `(1, 2, 3)`
- **مجموعه:** عناصر *بدون تکرار* و بدون ترتیب — `{1, 2, 3}`

## خطاها و دیباگ

### انواع خطا

- **خطای نحوی (Syntax Error):** غلط در دستور زبان.
- **خطای زمان اجرا (Runtime Error):** مثل تقسیم بر صفر.
- **خطای منطقی (Logic Error):** برنامه اجرا می‌شود ولی نتیجه اشتباه است.

### روش‌های دیباگ

1. **چاپ کردن (Print Debugging):** نمایش مقدار متغیرها در مراحل مختلف.
2. **خواندن پیام خطا:** معمولاً نوع و محل خطا مشخص می‌شود.
3. **استفاده از دیباگر:** اجرای گام‌به‌گام کد.
